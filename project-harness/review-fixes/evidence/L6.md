## 3. Findings

### [L6-01] No cross-session e2e test for persistent memory recall

**Severity:** P2 (gap in coverage) · **Confidence:** Confirmed

`e2e/scenarios/` has no scenario that: (1) runs dialogue to build session turns, (2) calls `POST /v1/admin/memories/consolidate/{npc_id}`, (3) starts a NEW session, (4) calls dialogue again and asserts the NPC references the consolidated memory. `scenario_memory_consolidation.py` only verifies memory creation, not cross-session retrieval.

**Fix sketch:** Add `e2e/scenarios/scenario_cross_session_memory.py` that seeds an NPC, talks to it, consolidates, clears the in-process session cache (or uses a second player_id), then dialogue-calls again and asserts `memory_recalled=true` in the response.

---

### [L6-02] ARCHITECTURE.md misidentifies runtime prompt location

**Severity:** P3 (doc drift) · **Confidence:** Confirmed

`docs/ARCHITECTURE.md:762` says `prompts/<engine>/` (relative to repo root) holds versioned LLM templates. The actual path is `src/npc_engine/prompts/<engine>/`. The root `prompts/` directory contains only canned response YAML (`prompts/canned/`) and a legacy eval prompt. A developer following the doc would look in the wrong directory.

**Fix sketch:** Update `docs/ARCHITECTURE.md` table row to specify `src/npc_engine/prompts/<engine>/` for runtime prompts.

---

### [L6-03] `make demo-run ARGS=--dry-run` fails on Windows (UnicodeEncodeError, pre-existing ISSUE-100)

**Severity:** P2 (demo hygiene — dry-run rehearsal path is broken) · **Confidence:** Confirmed, re-verified

`demo_game/determinism_beat.py:64` contains a `→` (U+2192) in the narration string. On Windows with cp1252 stdout, `print()` raises `UnicodeEncodeError: 'charmap' codec can't encode character '→'`. The error fires before the `if runner.dry_run: return` guard (the `print_cue` call is before the guard). Confirmed by running `python -m demo_game.run --dry-run` — fails at ACT 10.

This is pre-existing (logged as ISSUE-100). Still OPEN on this branch.

**Fix sketch:** Either replace `→` with ASCII `->`, or set `PYTHONIOENCODING=utf-8` in the Makefile's `demo-run` target.

---

### [L6-05] `game_controller.py` docstring lists `npc_engine.engines.interaction` as a dependency (false — no actual import)

**Severity:** P3 (misleading doc) · **Confidence:** Confirmed
