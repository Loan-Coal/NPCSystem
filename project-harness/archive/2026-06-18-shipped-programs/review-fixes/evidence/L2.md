## Findings

### [L2-05] `scheme_writer.mark_scheme_discovered` issues a WRITE via bare `session.run` outside any transaction
Severity: HIGH · Confidence: Confirmed
`src/npc_engine/graph/scheme_writer.py:149` — `await session.run(_CYPHER_MARK_SCHEME_DISCOVERED, scheme_id=scheme_id)` is a WRITE (`SET s.status = 'discovered'`) auto-committed with no explicit tx. Sibling functions (`upsert_scheme`, `add_scheme_step`) use `begin_transaction` + commit. Inconsistent on a new scheme-lifecycle write path.
Fix: wrap in `async with await session.begin_transaction() as tx: await tx.run(...); await tx.commit()`.

### [L2-06] `dependencies_advanced.py` is a second, undeclared composition root
Severity: MEDIUM · Confidence: Confirmed
`src/npc_engine/api/dependencies_advanced.py` defines `@lru_cache` singletons for clique/treaty/oath/skill/chapter/mood/succession/agenda/military/need-decay/negotiation engines, imported by `get_tick_scheduler()` in `dependencies_engines.py:461-472`. CLAUDE.md: "`api/dependencies.py` is the sole composition root." DEC-042/DEC-076 bless `dependencies_engines.py` but not this split.
Fix: add DECISIONS entry blessing the split with a boundary rule, or fold back.

### [L2-07] `scheme_advance_tick` splits one logical op across two independent transactions
Severity: MEDIUM · Confidence: Confirmed
`src/npc_engine/engines/scheming/scheme_advance_tick.py:107-115` — `run_in_tx(_emit)` (mint Event) commits, then `add_scheme_step` opens a SECOND independent tx (link SCHEME_STEP). A crash between leaves an orphan Event with no step link; scheme never advances. Not atomic.
Fix: combine into one `run_in_tx`; add a tx-scoped `add_scheme_step` variant accepting `AsyncTransaction`.

### [L2-08] Scheme writer sub-functions own their own transactions — violates session-ownership rule
Severity: MEDIUM · Confidence: Confirmed
`src/npc_engine/graph/scheme_writer.py:82,118` — both call `session.begin_transaction()` internally. CLAUDE.md: only `graph_writer.py` opens/commits. New code extended the L2-03 pattern.
Fix: accept `tx: AsyncTransaction` param; callers use `run_in_tx`. Same fix as L2-07.

### [L2-09] `check_layers.py` misses intra-rank peer violations and silently skips unranked packages
Severity: LOW · Confidence: Confirmed
`scripts/check_layers.py:113` only fails when `importer_rank < imported_rank`; within-rank imports unchecked; `observability` gets `_UNKNOWN_RANK = -1` and is silently skipped — future Python there is invisible.
Fix: add `observability` to `LAYER_RANK`; add a test for unknown-package imports.

### [L2-10] `covert_event_factory` summary template resembles prompt content but lives outside `prompts/`
Severity: LOW · Confidence: Likely
`src/npc_engine/engines/scheming/covert_event_factory.py:33` — `_COVERT_SUMMARY_TEMPLATE` builds the Event `summary` data field. If `event.summary` reaches LLM context (as it does in the context builder), it effectively shapes LLM input and should be YAML in `prompts/`.
Fix: confirm whether `event.summary` enters LLM context; if yes, move to `prompts/scheming/`; if no, document the determination in-file.

### [L2-11] `dependencies_engines.py` exceeds its DEC-076 growth cap (~513 lines)
Severity: LOW · Confidence: Confirmed
DEC-076 (2026-06-09) capped the file at 400 lines; scheme factories (`get_scheme_advance_tick`, `get_scheme_detection_tick`, lines 344-361) + director/memory/goal factories pushed it past. Breach without a new DECISIONS entry.
Fix: DECISIONS entry acknowledging breach + per-engine submodule boundary, or extract advanced factories.
