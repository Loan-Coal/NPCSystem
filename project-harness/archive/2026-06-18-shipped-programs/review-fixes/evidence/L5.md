**Severity:** HIGH · **Confidence:** CERTAIN  
**Where:** `src/npc_engine/scheduler/tick_scheduler.py:303-676`  
**Evidence:** AST measurement: 373 lines, depth-7 control-flow nesting (tick loop → distributed-lease branch → try/except → engine-specific if → response-append guard → lock → status-store guard). DEC-042 grants a *file-size* waiver but DECISIONS.md contains no function-length waiver for `advance()` itself. CLAUDE.md §Coding principles states "no function or method may exceed 40 lines" and "control-flow nesting must not exceed 3 levels" both as **(strict)**.  
**Fix sketch:** Log a DEC entry granting an explicit function-length waiver for `advance()`, or extract a `_run_one_tick(tick_id, ...)` helper that encapsulates all per-tick engine dispatch, reducing `advance()` to the loop + pre/post-flight only.
