# EXP-10 — Proactive NPC-initiated dialogue (first slice)

**Goal / rationale:** NPCs currently only react. Phase 14 / success criterion 2: an NPC can hail
a co-located idle player with an unsolicited in-character line, making the world feel agentic.
DEC-073 approved the WS `proactive_line` message shape on 2026-06-09.

**⚠️ Dependency:** EXP-33 must be merged FIRST (both touch `main.py`). Dispatch EXP-10 in the
batch AFTER EXP-33 is integrated.

**First slice (worker scope):** A `ProactiveDialogueEngine` with one deterministic trigger
(unshared high-vividness memory ≥ threshold + player co-located ≥ N ticks). When triggered, calls
the LLM (via injected `LLMClientProtocol`) to produce one in-character line and emits it as a
`proactive_line` WS push. No scheduler wiring yet (slice 2).
