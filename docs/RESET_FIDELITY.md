exactly two tiers and **FULL requires that nothing survives**. **10 observed component(s) survived it**, and **6 store(s) could not be observed at all**. Either alone is sufficient to rule out FULL.

## Method

Snapshotted **96 components** (every node type, every edge type, the emotion store,
the game clock and the engine-status store), ran a mutating scenario, called `reset_world`, and
snapshotted again. A component counts as **cleared** only if the scenario changed it *and* it
returned to its pre-scenario digest. Components the scenario never touched prove nothing either
way and appear in neither table.

Mutations applied:

- `PATCH world_state (epoch=war, conditions=['northern_war'])`

## What could not be observed at all

These are in-process singletons from `src/npc_engine/api/dependencies_stores.py` with no read
endpoint. They are listed in `surviving` as `unknown:<name>` rather than omitted. **An
unobservable store is not an absent one** — silently dropping one is exactly how a PARTIAL reset
gets written up as a FULL one.

| Store | Why it cannot be read over HTTP |
|---|---|
| `session_store` | GET /v1/dialogue/pending is per-player and returns only queued items; there is no endpoint that dumps session history or turn state |
| `dialogue_context_cache` | PartialDialogueContextCache has no route at all |
| `embedding_index` | GET /v1/admin/debug/retrieval requires (npc_id, query) and returns ranked hits for that query; it cannot enumerate the index |
| `idempotency_service` | no route |
| `negotiation_store` | no route; state is reachable only by continuing a negotiation |
| `reindex_job_service` | GET /v1/admin/graph/reindex/{job_id} needs a job id known in advance; jobs cannot be listed |

## Consequences

- **The Wilson interval at `evals/sequence_runner.py:160` is not earned.** It is computed unconditionally today over k repetitions whose independence has now been measured and found absent. That is ISSUE-143, and this artifact is the evidence it needs.
- **EVAL-P12.4 must withhold the CI** and print the order-effect check (`SEQUENCE_STATS_POLICY` §4: Cochran's Q across repetition indices, first-vs-last McNemar) as the primary statistic in its place. A run printing neither has reported nothing.
- **PARTIAL is the correct and expected result here, not a failure of the measurement.** `reset_world` PATCHes `world_state.epoch` and `world_state.active_conditions` and nothing else (`evals/preconditions.py:84`) — no graph teardown, no `KNOWS_ABOUT` removal, no emotion store, no session cache. A FULL verdict from this code would have been the bug.
